# Rehear — запись и расшифровка разговоров на Mac

**Локальная транскрибация встреч, лекций и интервью с помощью Whisper.** Запишите микрофон и звук нужного приложения — получите текст с таймкодами, саммари и возможность задать вопросы по разговору. Аудио и текст обрабатываются на вашем Mac.

**Local meeting recorder and AI transcription for macOS.** Record microphone and system audio, transcribe with Whisper, generate summaries and ask questions locally. [English documentation →](README.en.md)

[**Скачать приложение для Mac →**](https://github.com/zan14314/rehear/releases/tag/v0.5.4) · [Сообщить об ошибке](https://github.com/zan14314/rehear/issues)

**Тестовая версия 0.5.4 · Apple Silicon M1 и новее · macOS 15+.** Intel и Windows не поддерживаются.

## Скачать

Готовый ZIP находится в [Releases](https://github.com/zan14314/rehear/releases). Кнопка GitHub «Code → Download ZIP» скачивает исходники, а не приложение.

1. Распакуйте архив и перенесите «Rehear.app» в «Программы».
2. Запустите приложение. Сборка пока без Developer ID и нотариализации Apple. Если macOS блокирует запуск и вы доверяете сборке, после первой попытки откройте «Системные настройки → Конфиденциальность и безопасность → Открыть всё равно» именно для Rehear. Не отключайте Gatekeeper глобально.
3. В начальной настройке выберите папку и скачайте модель. Для саммари, названий и чата нужна отдельная Qwen.
4. Для записи дайте доступ к микрофону и системному звуку. Для импорта файлов эти разрешения не нужны.

Модели рекомендуются по памяти: меньше 16 ГБ — Whisper Small; от 16 ГБ — Whisper Turbo и Qwen 4B. Это ориентир, скорость зависит от нагрузки и устройства.

## Для чего пригодится

- **Рабочий созвон:** записать разговор, найти договорённость в тексте и перейти к нужному моменту аудио.
- **Лекция или интервью:** импортировать запись, читать расшифровку и получить краткое содержание.
- **Длинная встреча:** искать слова во всех разговорах, уточнять детали через чат и проверять ответ по фрагментам записи.
- **Запись выбранного приложения:** захватывать звук приложения для звонков, не добавляя аудио остальных программ.

Запись → автоматическая расшифровка → чтение и поиск → саммари или вопросы. После скачивания моделей обработка доступна без интернета. Саммари и чат требуют отдельной модели Qwen.

## Возможности

- Запись микрофона, всего системного звука или выбранного приложения; переключение источников во время записи.
- Автоматическая транскрибация после остановки записи и импорт аудио/видео.
- Таймкоды с переходом к аудио, сплошной текст и саммари.
- Поиск по названиям и расшифровкам, правки текста с историей.
- Локальный чат по разговору с сохранением сообщений и ссылками на фрагменты.
- Объединение разговоров, экспорт, восстановление незавершённых записей.

## Приватность и ограничения

Аудио и тексты обрабатываются локально. Загрузчик моделей обращается к Hugging Face; модели не входят в ZIP. Открытие внешних ссылок и скачивание приложения также требуют интернета.

Это бета: распознавание, особенно музыки и вокала, может ошибаться. Проверки повторов и подозрительно коротких результатов уменьшают отдельные сбои, но не гарантируют точность. Чат ищет релевантные фрагменты, а не гарантирует полный анализ каждого слова длинной встречи. Другой физический M1 с macOS 15 ещё требует проверки.

## Обновление

При переходе с прежнего названия «Созвоны» закройте старое приложение, перенесите Rehear.app в «Программы» и запускайте Rehear. Старую Созвоны.app можно переместить в Корзину после проверки. Модели, настройки и записи общие; их удалять не нужно.


Дождитесь окончания обработки, закройте приложение через ⌘Q и замените его новой версией в «Программах». Модели и настройки находятся отдельно в `~/Library/Application Support/ru.personal.calls`; аудио и результаты — в выбранной папке разговоров. Не удаляйте эти папки при обновлении.

## Исходники и сборка

SwiftUI/AppKit, ScreenCaptureKit/CoreAudio и локальный Python-сервис. Основной код: `outputs/Созвоны/source/`. Структура сохранена для совместимости существующих сборочных скриптов.

Для сборки изменений на Apple Silicon нужны macOS 15+, Xcode Command Line Tools и Python 3. Готовый релиз используется как шаблон встроенного runtime; полностью автоматическая сборка всех сторонних компонентов с нуля пока не настроена.

```sh
python3 scripts/rebuild.py --template /path/to/Rehear-0.5.4-macOS-Apple-Silicon.zip
```

Скрипт извлечёт runtime из релиза, пересоберёт Swift/Python и проверит минимальную macOS всех Mach-O. Результат: `outputs/Созвоны/Rehear.app` и `Rehear.zip`. По умолчанию используется ad hoc подпись только для разработки. Она не сохраняет идентичность официальной тестовой сборки и может потребовать повторных разрешений. Для собственного настроенного сертификата задайте `CALLS_SIGN_IDENTITY`. Закрытые ключи подписи в репозиторий не входят.

```sh
python3 tests/test_transcription_guard.py
python3 tests/test_transcript_versions.py
```
