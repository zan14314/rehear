Rehear 0.5.4 — тестовая версия для Apple Silicon M1 и новее, macOS 15+.

Скачайте **Rehear-0.5.4-macOS-Apple-Silicon.zip** из Assets, распакуйте и перенесите Rehear.app в Программы. Для обновления закройте старую версию через ⌘Q и замените приложение. Модели и разговоры хранятся отдельно.

Модели скачиваются при первом запуске. Для саммари и чата нужна Qwen. Обработка локальная. Сборка пока без нотариализации Apple; инструкция запуска есть в README и внутри архива.

Исправлено: подозрительно короткая расшифровка после записи со сменой источников теперь перепроверяется. Обычные записи повторно не распознаются. Музыка и вокал всё ещё могут распознаваться неточно.

Внутри ZIP есть лицензии и архивы исходников сторонних компонентов. Приложение тестовое; резервные копии важных записей рекомендуются.
